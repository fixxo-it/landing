# Fixxo Landing Page

React-based landing site for Fixxo, converted from a static HTML template.

## Features
- **Dynamic Sticky Notes**: Hero section with scattering sticky notes (mouse & scroll interaction).
- **Service Grid**: Scattered cards with stagger animation.
- **Marquee**: Animated testimonials.
- **Responsive Design**: Built with Tailwind CSS.

## Tech Stack
- React 19
- Vite
- Tailwind CSS 3
- SWC

## Local Development

```bash
npm install
npm run dev
```

## Vercel Deployment

This project is ready for Vercel deployment.
1. Connect your GitHub repository to Vercel.
2. Ensure the "Root Directory" is set to `landing` (if it's in a subdirectory).
3. The Build Command should be `npm run build`.
4. The Output Directory should be `dist`.
